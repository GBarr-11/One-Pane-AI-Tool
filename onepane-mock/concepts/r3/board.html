What each one is really choosing

  • A gives up page space to stay out of the way. Best if analysts keep One Pane open all day.
  • B takes almost no space. It depends on finding SMC's reply box reliably, which is still a guess in smc-adapter.js.
  • C keeps today's floating card and puts the pipeline on screen. Good for trust and debugging, but it's the densest.

Color use

Core Red is still the only action color in all three. Accents stay smaller than red, as the book requires. The open question is the High confidence color. A and B keep round 2's green, which isn't in the book. C tries Signal Teal, which is.
